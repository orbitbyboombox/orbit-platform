# Access Control

Founder controla administradores, permisos y activación de Staff. Las cuentas Staff solo las activa el Founder; Customer y Staff ven únicamente su ámbito. Los accesos externos deben revocarse al terminar una relación laboral o incidente. Revisar periódicamente usuarios Supabase, miembros GitHub/Vercel/Google Cloud y permisos de Storage.

La baja de un Customer está prohibida: solo archivo. Un colaborador aprobado se desactiva o archiva; una invitación pendiente sí puede cancelarse/eliminarse conforme al flujo.
