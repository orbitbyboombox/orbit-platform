# Dependency Manifest

| Dependencia | Propósito |
|---|---|
| `next`, `react`, `react-dom` | Aplicación web y rendering |
| `@supabase/ssr`, `@supabase/supabase-js` | Auth, Database, Storage y sesiones |
| `zod`, `react-hook-form`, resolvers | Validación y formularios |
| `pdf-lib`, `qrcode` | Contratos/documentos y QR |
| `exceljs`, `read-excel-file`, `jszip` | Importación y exportación operacional |
| `lucide-react` | Iconografía |
| `next-themes`, Tailwind, `clsx`, `tailwind-merge`, CVA | Sistema visual |
| `ai`, `@ai-sdk/gateway` | Capacidades NOVA/IA preparadas |

Las versiones exactas están bloqueadas por `pnpm-lock.yaml`; ese archivo es la fuente de recuperación reproducible.
