# Staff Lifecycle

Invitación → onboarding → Pending Founder Approval → aprobación → Staff Profile → Portal activation/PIN → publicación de Event → solicitud de responsabilidad → aprobación Founder → Assignment + Settlement → aceptación/operación/check-in → liquidación/payroll → recibo SII → historial.

El Event Settlement es la única fuente financiera Staff. Cancelaciones son auditadas, alertan al Founder y no dependen de Timeline para confirmar.
