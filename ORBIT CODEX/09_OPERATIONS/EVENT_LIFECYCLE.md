# Event Lifecycle

Customer → Event Draft → configuración comercial/operacional → Ready → Published to Staff → requests → Founder approval → confirmed Assignment + Settlement → execution/check-in → Completed → financial closure/archive.

El Event es fuente de fechas, servicio, horas, lugar, Staff, pagos operacionales, costos, documentos, Portal, Calendar y Timeline. Cancelar Assignment recalcula y republica la oportunidad cuando corresponde; Timeline/notificaciones ocurren después del commit.
