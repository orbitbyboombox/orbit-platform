# ORBIT — Visual Consistency Report

## Marca

- Único maestro: `public/branding/ORBIT V1-0 SINFONDO.png`.
- Logotipo horizontal usado sin recorte ni distorsión.
- Isotipo derivado únicamente mediante recorte del lienzo maestro; conserva color, trazo, proporción y transparencia.
- Firma oficial preservada: ORBIT v1.0 · Developed by BOOMBOX · Powered by NOVA CORE.

## Sistema visual

- Tema oscuro aplicado en Login y aplicación interna.
- Radios, bordes y elevación mantienen los tokens existentes.
- Jerarquía coherente entre títulos de página, secciones, tarjetas, etiquetas y ayudas.
- Acciones principales se distinguen de acciones secundarias mediante contraste y tamaño.
- Objetivos táctiles críticos alcanzan al menos 44 px.

## Responsive

- Desktop: navegación expandida equilibrada con la marca.
- Tablet: navegación compacta usa el isotipo sin comprimir el logotipo horizontal.
- Mobile: topbar conserva marca, sesión y navegación; contenido prioriza una decisión por pantalla.
- Filtros extensos permanecen desplazables horizontalmente en CRM y etiquetas de Staff.

## Lenguaje

- Interfaz visible en español.
- Términos internos como repository, provider, mock y snapshot no se presentan como microcopy de usuario en las áreas ajustadas.
- Estados vacíos explican qué ocurrirá y ofrecen una próxima acción cuando corresponde.
