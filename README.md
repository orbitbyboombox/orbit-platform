# ORBIT Platform — DEV-003

Authenticated, responsive application shell for the ORBIT Platform. Business modules remain presentation-only placeholders.

## Getting started

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Validation

```bash
pnpm lint
pnpm typecheck
pnpm build
```

See `docs/architecture.md` for boundaries and dependency direction.
